# Bible Verse of the Day Sample

This page reads the Bible Gateway Verse of the Day Atom feed and presents the
current verse in a mobile-friendly layout.

## What It Does

- fetches the live Atom feed from Bible Gateway
- shows the verse title, update date, and summary text
- links back to the original source

## What To Observe

- the page is centered and easy to read on small screens
- the verse text is displayed like a reading card
- the source button takes you back to Bible Gateway

## Useful Notes

- the page fetches the feed on the server, so browser CORS does not get in the
  way
- you can add caching later if you want to keep a local snapshot of the feed
